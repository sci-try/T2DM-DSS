Iraq injectable algorithm v3. Routing starts from current regimen, then how far HbA1c is above the individualised target (default 7.0% if not provided) and BMI. Patients with severe unstable hyperglycaemia are out of scope for this pathway. GLP-1 RA accessible / tolerated (tool input iq_glp1_ra_access, binary Yes/No, default No): when set to Yes, GLP-1 RA monotherapy and separate LA GLP-1 injection options are allowed where the engine uses them. When No, those paths are off; FRC (basal + GLP-1 fixed-ratio) is not gated on this field and is assumed feasible. When access is No and BMI > 30 with HbA1c < 2% above target, first injectable is FRC only (no parallel basal-alone start). Obesity (BMI > 30) first injectable with access No avoids premix; with access Yes, FRC is not preferred over separate injections. Premix appears only where the prose allows (e.g. BMI ≤ 30 regular meals, or when FRC unavailable); irregular meal patterns suppress premix in those branches. Established Premix or Basal-bolus with inadequate control routes to simplification (transition to FRC where accessible), not first-injectable selection. After BI (max) + GLP-1 RA + rapid-acting insulin, Iraq output intensifies to basal-bolus (optimise BI + GLP-1 RA + prandial first); a premix alternative is offered only with regular meals. Every Iraq recommendation also carries a standardised Key Considerations block (HbA1c ~7% individualised; 2nd-gen basal; GLP-1 RA choice; FRC benefits; basal-bolus; premix; irregular-meal warning).

Iraq — Textual description

Scope — Severe unstable hyperglycaemia

The Iraq pathway in this tool starts from current injectable regimen and routings driven by HbA1c vs target and BMI. It does not model patients with severe unstable hyperglycaemia, who should be managed urgently outside this decision tree. (Türkiye still applies a TEMD-aligned severe gate; see the Türkiye tab and Shared gates.)

Step 0 — First injectable selection

How far HbA1c is above the individualised target and BMI determine the starting injectable:

  • HbA1c less than 2% above target, BMI ≤ 30: Therapy (tool): Start basal insulin & titration — 2nd-generation basal, titrate up to 0.5 U/kg/day. Next steps focus on titration to fasting target and reassessment (dosing ceiling is stated in Therapy, not repeated in Next steps). 2nd-generation basal insulins are preferred overall; especially in elderly / CKD. Simpler regimens precede premix/basal-bolus.
  • HbA1c less than 2% above target, BMI > 30: If GLP-1 RA accessible / tolerated = Yes: prefer Start GLP-1 RA monotherapy (escalation: add basal or FRC if uncontrolled; then rapid-acting per later steps). BMI/weight favor GLP-1 RA–based paths. If access = No: Start BI + GLP-1 RA (FRC) only (no parallel basal-only start; FRC is how combined therapy is delivered).
  • HbA1c 2% or more above target, BMI ≤ 30: If monotherapy LA access = Yes: Start BI + GLP-1 RA (FRC or separately); premix only as a complex alternative when options are inaccessible (with hypoglycaemia/adherence caveats); premix omitted if irregular meals. If access = No: generally Start BI + GLP-1 RA (FRC); premix only if FRC is not available.
  • HbA1c 2% or more above target, BMI > 30: If monotherapy LA access = Yes: Start BI + GLP-1 RA (FRC or separately) without preferring FRC over separate injections. If access = No: Start BI + GLP-1 RA (FRC) only (no premix in this obesity-initiation row; Iraq FRC access note applies).

Step 1 — Escalation from basal-only

If HbA1c remains above target on basal insulin alone, routing splits on how far HbA1c is above target:

  • Less than 2% above target: titrate basal to fasting target (up to ~0.5 U/kg/day) and add GLP-1 RA (FRC or separately).
  • 2% or more above target: move to a BI + GLP-1 RA combination; premix is offered only as an alternative when FRC / free combination is unavailable (omitted if irregular meals).

If GLP-1 RA accessible / tolerated = Yes: FRC or separate basal + GLP-1 RA (no enforced preference). If No: use FRC (assumed feasible); explanation references inaccessible or intolerable monotherapy LA GLP-1 RA. For BMI > 30 with access Yes, rationale includes weight-related favoring of GLP-1 RA–based combinations.

Step 1b — Escalation from GLP-1 RA alone

If HbA1c remains above target on GLP-1 RA monotherapy, routing splits on how far HbA1c is above target:

  • Less than 2% above target: optimise GLP-1 RA and add basal insulin (FRC or separately) — GLP-1 RA alone does not adequately control fasting glucose.
  • 2% or more above target: start BI + GLP-1 RA combination targeting both fasting and postprandial glucose.

When access is No, the incretin-containing lane is delivered via FRC.

Step 2 — Add stepwise prandial insulin

If HbA1c remains above target on BI + GLP-1 RA (FRC or separately when LA access allows): optimise BI + GLP-1 RA, then add stepwise prandial insulin starting at the largest meal → BI (max dose) + GLP-1 RA + Rapid-acting insulin.

Titrate basal insulin to its maximum tolerated dose; titrate prandial dose on postprandial glucose. If persistent hyperglycaemia continues, intensify to basal-bolus; a premix alternative applies only with regular meals.

Step 3 — Final intensification

If HbA1c remains above target on BI (max) + GLP-1 RA + rapid-acting insulin:

  • Intensify to basal-bolus for full basal and prandial control (optimise BI + GLP-1 RA + prandial first).
  • Alternative: premix insulin if needed or access is limited — offered only with regular meals (suppressed under irregular meals).
  • If HbA1c and/or prandial control remain inadequate, prioritise adherence (injection–meal alignment, education, SMBG/CGM, follow-up) before adding further complexity.

Step 4 — Established premix or basal-bolus (simplification)

When the current regimen is already premixed insulin or basal-bolus with inadequate control, the Iraq pathway prefers simplification rather than first-injectable selection:

  • On premix: prefer transition to FRC (BI + GLP-1 RA) where accessible (simplifies regimen, improves adherence, targets FPG + PPG); alternative is intensification to basal-bolus. Premix challenges (rigid meals, hypoglycaemia risk, difficult titration) are surfaced.
  • On basal-bolus: prefer transition to FRC where accessible; alternative is switching to premix — suppressed under irregular meals (FRC-only). Basal-bolus challenges (injection burden, low adherence, hypoglycaemia) are surfaced.
  • Recurrent hypoglycaemia, when flagged, reinforces the simplification rationale.

Standing notes (always shown for Iraq)

  • GLP-1 RA choice should be guided by patient-specific considerations: established CVD, CKD, desired weight benefit, access and cost (affordability).
  • Basal insulin: 2nd-generation agents (degludec, glargine U-300) are preferred over older generations due to lower hypoglycaemia risk.
  • Premix agents: may be used as alternatives if other options are not accessible locally (suppressed when irregular meal patterns = Yes; then prefer FRC).
  • In Iraq, FRC can be a pragmatic way to deliver GLP-1 RA therapy; when monotherapy LA GLP-1 RA is unavailable, FRC is often the most feasible GLP-1 RA access route in tool recommendations.
  • Complex insulin (premix or basal-bolus) is reserved until simpler strategies fail or are unavailable.

Traceability: severe gate and presentation glucoses follow TEMD Diabetes Mellitus Kılavuzu 2024 §9.2.3 and Bölüm 8 insulin recommendations; first-line injectable comorbidity steering follows Şekil 9.4 / §9.2.4 as implemented in py/engine.py (injectable layer only). SGK reimbursement notes for FRC at BMI <35 kg/m² are access policy, not a TEMD clinical threshold.

Türkiye — Textual description

1) Severe hyperglycaemia / insulin-start (TEMD §9.2.3, Bölüm 8)

Any of: hyperglycaemic symptoms (e.g. polyuria, polydipsia, nocturia), weight loss / catabolic signs, suspected DKA/HHS (and similar), HbA1c ≥ 9%, fasting / APG > 250 mg/dL, or random PG > 300 mg/dL (both glucose fields converted from mmol/L with ×18.018) → start or intensify insulin; engine text mirrors TEMD (prefer basal–bolus or premix; continue metformin when not contraindicated; monitoring; consider type 1 / LADA).

2) Intensification on FRC

On FRC, target unmet → add rapid-acting insulin (may be off-label).

On FRC + rapid, target unmet → basal-bolus or premixed insulin (premix omitted if irregular meal patterns = Yes).

3) Simplification

On basal-bolus or premix with recurrent hypoglycaemia → switch to FRC.

4) Intensification on basal insulin

On basal insulin, target unmet or PPG uncontrolled → switch to FRC.

5) First injectable

  • HbA1c <2% above target, BMI > 30 → FRC.
  • HbA1c <2% above target, BMI ≤ 30 → basal insulin unless any Şekil 9.4 flag (ASCVD, HF, CKD, MASLD) → FRC.
  • HbA1c ≥2% above target with HbA1c < 9% (otherwise severe gate) → FRC.
  • HbA1c missing: BMI >30 → FRC; BMI ≤30 → basal unless comorbidity flags → FRC.

Basal insulin rows add TEMD-style preference for long-acting / newer-generation basal analogues where available.

SGK / access (not TEMD): if FRC is recommended and BMI < 35 kg/m², add reimbursement / out-of-pocket comment.

Shared logic (all countries)

Severe hyperglycaemia gate (Türkiye TR only)

For Türkiye (TR), before other TR branches the engine applies TEMD 2024 §9.2.3 / Bölüm 8: symptom clusters (hyperglycaemic symptoms, weight loss/catabolic signs, suspected metabolic emergency), HbA1c ≥ 9%, fasting / APG > 250 mg/dL, or random PG > 300 mg/dL (mmol/L fields × 18.018). Output expands to basal–bolus vs premix + metformin continuation + monitoring + LADA/T1 distinction note.

Iraq (IQ) uses regimen-first routing only — this gate is not applied. Severe unstable states remain clinician-led.

Irregular meal patterns

Optional Yes / No (default No). When Yes, recommendations that would offer premixed insulin as an option instead favour FRC or basal-bolus only, depending on branch (Iraq and Turkey).

Default HbA1c target

If the user does not provide an individualised HbA1c target but does provide a current HbA1c value, the engine uses a default target of 7.0% and adds a comment to the output.

How the target drives routing

The engine computes HbA1c (current) − HbA1c (target) internally. The HbA1c target field in the tool accepts the individualised target value; how far the current HbA1c is above that target is then used as the primary routing variable for first injectable selection.
