Iraq injectable algorithm v3. Routing is based on how far HbA1c is above the individualised target (default 7.0% if not provided) and BMI. Monotherapy LA GLP-1 RA access (tool input iq_glp1_ra_access): when set to Yes, GLP-1 RA monotherapy and separate LA GLP-1 injection options are allowed where the engine uses them. When No or unset, those paths are off; FRC (basal + GLP-1 fixed-ratio) is not gated on this field and is assumed feasible. When access is No / unset and BMI > 30 with HbA1c < 2% above target, first injectable is FRC only (no parallel basal-alone start). Obesity (BMI > 30) first injectable with access No / unset avoids premix; with access Yes, FRC is not preferred over separate injections. Premix appears only where the prose allows (e.g. BMI ≤ 30 regular meals, or when FRC unavailable); irregular meal patterns suppress premix in those branches. After BI (max) + GLP-1 RA + rapid-acting insulin, Iraq output optimises basal-bolus style coverage and adherence (premixed insulin is not offered in this IQ step).

Iraq — Textual description

Shared gate — Severe hyperglycaemia

If catabolic symptoms are present, or HbA1c ≥ 10%, or FPG > 300 mg/dL (FPG may be entered as mg/dL or mmol/L; mmol/L is converted in the tool using × 18.018), the algorithm immediately recommends start / intensify insulin. This overrides all other branches.

Step 0 — First injectable selection

How far HbA1c is above the individualised target and BMI determine the starting injectable:

  • HbA1c less than 2% above target, BMI ≤ 30: Therapy (tool): Start basal insulin & titration — 2nd-generation basal, titrate up to 0.5 U/kg/day. Next steps focus on titration to fasting target and reassessment (dosing ceiling is stated in Therapy, not repeated in Next steps). 2nd-generation basal insulins are preferred overall; especially in elderly / CKD. Simpler regimens precede premix/basal-bolus.
  • HbA1c less than 2% above target, BMI > 30: If monotherapy LA GLP-1 RA access = Yes: prefer Start GLP-1 RA monotherapy (escalation: add basal or FRC if uncontrolled; then rapid-acting per later steps). BMI/weight favor GLP-1 RA–based paths. If access = No / unset: Start BI + GLP-1 RA (FRC) only (no parallel basal-only start; FRC is how combined therapy is delivered).
  • HbA1c 2% or more above target, BMI ≤ 30: If monotherapy LA access = Yes: Start BI + GLP-1 RA (FRC or separately); premix only as a complex alternative when options are inaccessible (with hypoglycaemia/adherence caveats); premix omitted if irregular meals. If access = No / unset: generally Start BI + GLP-1 RA (FRC); premix only if FRC is not available.
  • HbA1c 2% or more above target, BMI > 30: If monotherapy LA access = Yes: Start BI + GLP-1 RA (FRC or separately) without preferring FRC over separate injections. If access = No / unset: Start BI + GLP-1 RA (FRC) only (no premix in this obesity-initiation row; Iraq FRC access note applies).

Step 1 — Escalation from basal-only

If HbA1c remains above target on basal insulin alone (after maximal titration where applicable on the BMI ≤ 30 ladder): escalate to BI + GLP-1 RA. If monotherapy LA GLP-1 RA access = Yes: FRC or separate basal + GLP-1 RA (no enforced preference). If No / unset: use FRC (assumed feasible); explanation references inaccessible or intolerable monotherapy LA GLP-1 RA. For BMI > 30 with access Yes, rationale includes weight-related favoring of GLP-1 RA–based combinations.

Step 2 — Add rapid-acting insulin

If HbA1c remains above target on GLP-1 RA monotherapy, escalate first to BI + GLP-1 RA: FRC or separately when monotherapy LA GLP-1 RA access = Yes (no enforced FRC preference); when access is No / unset remain on/increase use of FRC.

If HbA1c remains above target on BI + GLP-1 RA (FRC or separately when LA access allows): → BI (max dose) + GLP-1 RA + Rapid-acting insulin.

Titrate basal insulin to its maximum tolerated dose; add prandial rapid-acting insulin starting at the largest meal.

Step 3 — Final intensification

If HbA1c remains above target on BI (max) + GLP-1 RA + rapid-acting insulin:

  • Optimise basal-bolus-style coverage with the GLP-1 RA component (max basal, titrate rapid-acting across meals).
  • If HbA1c and/or prandial control remain inadequate, prioritise adherence (injection–meal alignment, education, SMBG/CGM, follow-up) before adding further complexity.
  • Premixed insulin is not listed in this Iraq step (tool output).

Standing notes (always shown for Iraq)

  • GLP-1 RA choice should be guided by patient-specific considerations: established CVD, CKD, desired weight benefit, access and cost (affordability).
  • Basal insulin: 2nd-generation agents (degludec, glargine U-300) are preferred over older generations due to lower hypoglycaemia risk.
  • Premix agents: may be used as alternatives if other options are not accessible locally (suppressed when irregular meal patterns = Yes; then prefer FRC).
  • In Iraq, FRC can be a pragmatic way to deliver GLP-1 RA therapy; when monotherapy LA GLP-1 RA is unavailable, FRC is often the most feasible GLP-1 RA access route in tool recommendations.
  • Complex insulin (premix or basal-bolus) is reserved until simpler strategies fail or are unavailable.

Turkey — Textual description

1) Severe hyperglycaemia override

Catabolic symptoms, HbA1c ≥ 10%, or FPG > 300 mg/dL (after unit conversion) → start / intensify insulin immediately.

2) Intensification on FRC

On FRC, target unmet → add rapid-acting insulin (may be off-label).

On FRC + rapid, target unmet → basal-bolus or premixed insulin (premix omitted if irregular meal patterns = Yes).

3) Simplification

On basal-bolus or premix with recurrent hypoglycaemia → switch to FRC.

4) Intensification on basal insulin

On basal insulin, target unmet or PPG uncontrolled → switch to FRC.

5) First injectable

  • HbA1c less than 2% above target, BMI ≤ 30 → basal insulin.
  • HbA1c less than 2% above target, BMI > 30 → FRC.
  • HbA1c 2% or more above target (any BMI) → FRC.

Turkey reimbursement note: if FRC is recommended and BMI < 35 kg/m², treatment may be out-of-pocket.

Shared logic (all countries)

Severe hyperglycaemia gate

Applied before any country-specific logic. If catabolic symptoms are present, or HbA1c ≥ 10%, or FPG > 300 mg/dL (optional FPG field; mmol/L converted with × 18.018), the engine immediately returns "Start / intensify insulin (severe hyperglycaemia)".

Irregular meal patterns

Optional Yes / No (default No). When Yes, recommendations that would offer premixed insulin as an option instead favour FRC or basal-bolus only, depending on branch (Iraq and Turkey).

Default HbA1c target

If the user does not provide an individualised HbA1c target but does provide a current HbA1c value, the engine uses a default target of 7.0% and adds a comment to the output.

How the target drives routing

The engine computes HbA1c (current) − HbA1c (target) internally. The HbA1c target field in the tool accepts the individualised target value; how far the current HbA1c is above that target is then used as the primary routing variable for first injectable selection.
